📝 Blog Maker – Full Stack MERN Blog Platform

A modern, full-stack blog application built with React, Node.js, Express, and MongoDB, featuring a clean UI, publishing workflow, and real-world blog management capabilities.

🚀 Live Demo

Frontend (Vercel): [(https://blog-generator-jade.vercel.app/)](https://blog-generator-jade.vercel.app/)

Backend API (Render): https://blog-generator-mmag.onrender.com

✨ Features
🖥️ Frontend (React + Vite)

Modern, responsive UI

Create, edit, delete blogs

Draft & publish workflow

View all blogs and published blogs separately

Full blog view with:

📊 View counter

❤️ Like system

Professional animations & transitions

Clean navigation with dedicated pages

🛠️ Backend (Node.js + Express)

RESTful API architecture

MongoDB with Mongoose schemas

Blog publishing system

Incremental views & likes

Robust error handling middleware

Production-ready structure

🧠 Blog Workflow

Blogs are created as drafts by default

Blogs can be:

Published

Unpublished

Edited anytime

Only published blogs appear in the Published Blogs section

Views automatically increase on blog open

Likes update in real time
